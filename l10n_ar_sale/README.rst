========================
Argentinean Sale Report
========================

This module adapts Sales quotations/orders reports for Argentinean companies.

Features
========

- Dynamic report template routing for AR companies only.
- Argentinean document header variables (`X`, legal legend, date/number).
- Sales document information block with customer, tax data and commercial fields.
- Dedicated footer pager for PDF output.

Usage
=====

1. Install module.
2. Print a quotation or sales order from a company in Argentina.
3. Report uses the localized AR template.

For companies outside Argentina, native Odoo report templates remain unchanged.
